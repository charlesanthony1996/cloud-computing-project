# ADR-002: Streaming ML inference pipeline with window based LSTM

## Status
Accepted

## Context
The system processes continuous IMU sensor data and must detect freezing of gait events using a machine learning model.
Real time inference requires handling streaming data, fixed length inputs, and preprocessing before model execution

Raw sensor data is noisy and variable in length, while the ML model expects a fixed size input tensor

## Decision
We implement a **window based streaming pipeline**
1. Sensor samples are ingested continuously
2. Samples are buffered until a fixed window size (128 timesteps) is reached
3. The window is normalized in a dedicated feature extraction service
4. A lightweight LSTM model performs binary FoG classification

Each pipeline stage is isolated in its own service

## Consequences


### Positive
- Clear, explainable ML pipeline
