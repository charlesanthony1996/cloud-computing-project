# ADR-003: Observability and carbon aware control using prometheus and grafana

## Status
Accepted

## Context
The project requires monitoring, observability and sustainability awareness. Im must expose system health, ML behaviour and control decisions while supporting
dashboards and potential alerting

Additionally, the system introduces a carbon aware controller that dynamically adapts workload intensity based on system state and ML predictions

## Decision
We integrate **Prometheus** for metrics collection and **Grafana** for visualization. Each service exposes a /metrics endpoint with
relevant metrics, including:
- Buffer sizes
- Prediction counts
- FoG event counts
- Generator rates
- Carbon controller state and rate changes

The carbon controller adjusts the data generation rate based on
- Buffer pressure
- ML FoG predictions

## Consequences

### Positive
- Full system observability with minimal overhead
- Real time visualization of ML and control behaviour
- Supports sustainability analysis and reporting
- Aligns with industry standard monitoring stacks
- Enables future alerting and autoscaling extensions

### Negative
- Requires additional services and configuration
- Metrics must be carefully designed to avoid noise
- Carbon impace is estimated indirectly, not measures physically

## Alternatives considered
- **Custom logging based monitoring**
Rejected due to lack of aggregation and visualization
- **Cloud managed monitoring tools**
Rejected to keep the project self-contained and reproducible

## Sustainability considerations
Dynamic rate control reduces unnecessary computation during low risk periods, lowering energy usage.
Observability enables informed decisions about trade-offs between performance, cost and carbon footprint
